# U.S. Census Bureau — American Community Survey (ACS)

## Overview
Census socioeconomic data is hardcoded in the notebook from
official ACS 2022 5-year estimates. It does not require an
API call or file download.

## Source
- **Organization:** U.S. Census Bureau
- **Dataset:** American Community Survey (ACS) 5-Year Estimates
- **Year:** 2022 (5-year pooled estimates: 2018–2022)
- **URL:** https://census.gov/data/developers/data-sets/acs-5year.html

## Variables Used
| Variable Code | Description | Used For |
|---|---|---|
| DP03_0062E | Median household income in dollars | RQ10 |
| DP02_0068PE | % adults 25+ with bachelor's degree or higher | RQ11 |
